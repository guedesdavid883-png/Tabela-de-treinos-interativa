# Tabela-de-treinos-interativa
Este é um projeto pessoal desenvolvido para praticar HTML, CSS e JavaScript, criando uma tabela de treinos simples, organizada e interativa.
A ideia é facilitar o acompanhamento dos treinos no dia a dia, permitindo visualizar os exercícios, séries e dicas de execução de forma rápida e prática.
O projeto também serve como uma forma de colocar em prática conceitos de desenvolvimento web enquanto construo algo que realmente posso utilizar.
